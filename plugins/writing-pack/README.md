# writing-pack

Four skills that help your agents write things people can actually use.

| Skill                      | Use it when an agent is...                                                        |
| -------------------------- | --------------------------------------------------------------------------------- |
| `writing-for-humans`       | writing anything a person reads: READMEs, release notes, docs, UI text, errors    |
| `writing-adrs`             | recording a technical decision and why it was made                                |
| `writing-developer-guides` | writing a guide that another agent or a developer will look things up in          |
| `clarifying-requirements`  | handed a vague request, before it starts building the wrong thing                 |

## Make them yours

Each skill ends with an **Adapt for your repo** section. It lists the few things
worth setting for your project, like where your decision records live or which
file holds your voice rules. The skills work without it. They get sharper with it.

## Where these come from

These started as the writing skills in [DorkOS](https://github.com/dork-labs/dorkos),
tuned over months of agents writing changelogs, docs and decision records. This
pack is the general version, with the DorkOS-only rules taken out.
