# Use all your accounts

With several Claude Code, Codex or OpenCode accounts on this computer, flow can spread its work across them. When one reaches its limit, work moves to another instead of stopping.

**The full guide lives on the DorkOS site: [Use all your accounts](https://dorkos.ai/docs/guides/flow/use-all-your-accounts).** It covers the three roles (main, rotation, kept out), setup in the terminal and in the DorkOS app, and what to do when something looks wrong.

This is built for one person using their own accounts. Whether that fits Anthropic's terms, or any other service's, is your call to judge. Don't use it to share accounts between people. Keep a work or client account out unless you are allowed to use it this way.

The short version:

```bash
flow accounts setup          # asks, then shows every change before making it
flow accounts setup --help   # every flag, for scripts and agents
flow accounts                # each account's role and room left
```

## Which projects an account may work in

DorkOS decides which accounts each project may use: each project's Flow settings have **Accounts this project may use**, one checkbox per account, and DorkOS holds every chat, schedule and handoff there to it. `flow next` and `flow drain` in the terminal follow the same rule.

This replaces flow's older **Only for these repos** list on a kept-out account. In Settings → Flow, that account's row says what DorkOS would do, and moves the list only when you press **Move it**. The move never lets an account work anywhere it couldn't before, and it leaves alone an account DorkOS already limits. Until every project runs flow 0.52 or newer, flow keeps its own list too, and both rules apply.

To see each account's limits, see [Account usage](./account-usage.mdx).
