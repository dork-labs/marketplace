# Draining in parallel

`flow drain --parallel 3` carries three ready items at once, each in its own worktree on the account with the most room. A separate reviewer reads every push; `flow pr` opens the PR only after a clean review at the branch head.

## Before you start

Allow each account flow may spend with `flow accounts set <id> --role rotation`. Each user judges their own use of more than one account against Anthropic's terms.

## Where sessions run

`--host` picks `cli`, `cmux` or `dorkos`; `auto` tries cmux, DorkOS, then CLI.

## What each line means

- `claimed on <account> (cli)`: a worker started.
- `reviewer started at 4be1c2d`: a push is under review.
- `sent review-findings`: the worker got the findings.
- `sent open-pr`: the review came back clean.
- `moved to <account>`: an account ran out, so the work moved.
- `parked: <reason>`: a person is needed.

## What happens at a limit

Near a limit, the worker finishes its step, checkpoints and stops. If the account resets within `drain.waitIfResetWithinMinutes`, the run waits. If only one model ran out, it goes on with the next in `drain.modelFallback`. Otherwise a session on another account continues from `HANDOFF.md`.

## Ask or auto

`handoff` in `fleet.json` decides: `auto` moves the run at once; `ask` posts one comment with the `flow handoff <id> --to <account>` command and waits for the reset. `flow handoff <id> --wait` keeps a run where it is.

## Caps

New sessions wait while load per CPU reaches `drain.maxLoadPerCpu` or an account has `drain.maxLivePerAccount` sessions. After `drain.maxReviewRounds` rounds the run parks.

## Terminal or schedule

In a terminal, `flow drain` repeats every `drain.pollSeconds` until done or Ctrl-C. A schedule runs `flow drain --tick`.

## Permissions

Workers start in `drain.permissionMode`, default `acceptEdits`, which runs only what your repo's settings allow. `bypassPermissions` is your call per project; your guard hooks still run.

## Parts

Sessions read `templates/drain/worker-brief.md` and `templates/drain/reviewer-brief.md`. `flow watch` waits on a PR by hand.
